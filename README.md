# ⌨️ TypTone — Pashto Typing Tutor

**TypTone** is an interactive web-based typing tutor designed to help users learn and improve their **Pashto keyboard typing skills**.

The platform provides structured typing lessons that gradually progress from individual letters to words, sentences, and longer texts. Users can practice directly with an interactive keyboard while tracking their typing progress.

## ✨ Features

* ⌨️ **Pashto Virtual Keyboard**

  * Interactive Pashto keyboard layout
  * Visual keyboard feedback while typing
  * Practice Pashto letters according to their keyboard positions

* 📚 **Progressive Typing Lessons**

  * Beginner-friendly lessons
  * Letter-by-letter practice
  * Word practice
  * Sentence practice
  * Longer text and paragraph practice
  * Hundreds of lessons for continuous learning

* 🎯 **Typing Practice**

  * Real-time typing exercises
  * Highlighted keys
  * Typing accuracy tracking
  * Typing speed tracking
  * Progress indicators

* 🔒 **Lesson Progression**

  * Lessons are organized in levels
  * Completed lessons unlock additional lessons
  * Users can continue from their current progress

* 📊 **Learning Statistics**

  * Typing speed
  * Accuracy
  * Completed lessons
  * Overall learning progress

* 📱 **Responsive Design**

  * Works on desktop computers
  * Tablet-friendly interface
  * Mobile-friendly layout

* 🌐 **Pashto-First Experience**

  * Pashto content
  * RTL interface
  * Designed specifically for learning Pashto typing

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/FazlahmadHotaki/TypTone.git
```

### 2. Open the project

```bash
cd TypTone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development address provided by Vite.

## 🏗️ Build for Production

Create a production build with:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 📖 How TypTone Works

TypTone follows a progressive learning system:

```text
Pashto Letters
      ↓
Keyboard Positions
      ↓
Letter Combinations
      ↓
Words
      ↓
Short Sentences
      ↓
Long Sentences
      ↓
Paragraphs
      ↓
Advanced Typing Practice
```

This approach allows beginners to gradually develop familiarity with the Pashto keyboard before moving to more complex typing exercises.

## 🎓 Lesson System

TypTone contains a large collection of typing exercises organized into progressive lessons.

A typical lesson can include:

* Lesson number
* Difficulty level
* Practice letters
* Practice words
* Practice sentences
* Typing text
* Progress percentage
* Typing performance

The difficulty increases gradually as the learner progresses through the lessons.

## ⌨️ Pashto Typing

TypTone focuses on learning the placement and use of Pashto characters on a standard keyboard.

Learners practice:

```text
Letters
   ↓
Key Positions
   ↓
Combinations
   ↓
Words
   ↓
Sentences
   ↓
Real Text
```

The goal is to help users develop **touch-typing skills** so they can type Pashto faster and more accurately without constantly looking at the keyboard.

## 📊 Progress Tracking

TypTone provides feedback while the learner is typing, helping users understand their performance and improve over time.

Important metrics include:

* **Speed**
* **Accuracy**
* **Progress**
* **Completed lessons**
* **Current lesson**
* **Typing performance**

## 🎯 Project Goal

The main goal of TypTone is to provide a simple and effective platform for people who want to learn **Pashto keyboard typing**.

Instead of memorizing the keyboard layout separately, learners can practice the letters directly through interactive exercises and gradually move toward real Pashto text.
